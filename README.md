# Planilha de Organização para o Imposto de Renda

Este projeto é uma planilha desenvolvida para ajudar no controle, organização e preenchimento da declaração anual do Imposto de Renda Pessoa Física (IRPF). 

##  O que a planilha contem? 

*   **Cadastro do Titular:** Centraliza os dados pessoais e documentos obrigatórios (CPF, Título de Eleitor, endereço).
*   **Controle de Bancos :** Organiza os saldos de contas e aplicações financeiras no final do ano, com espaço para registrar o nome do arquivo de comprovante (`.pdf`).
*   **Registro de Rendimentos:** Espaço para lançar os recebimentos mês a mês (como holerites e salários).
*   **Lista de Bancos integrada:** Possui uma lista com os códigos oficiais dos principais bancos para facilitar o preenchimento.


##  Estrutura dos Arquivos

*   `README.md`: Este arquivo com as explicações do projeto.
*   `/images`: Pasta reservada para guardar prints visuais da planilha.

*Nota: Todos os dados de pessoas e valores incluídos nos arquivos de teste são 100% fictícios.*
